# aafinatech.com

Corporate website of Aafina Technologies & Consulting Services Pvt. Ltd.

Static site (no build step). Hosted on Hostinger with auto-deploy from the `main` branch.

- `index.html` — the full site (styles, scripts and director photos are inline)
- `og-image.png` — social share preview image
- `robots.txt`, `sitemap.xml` — search engine files
